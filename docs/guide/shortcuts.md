# 快捷键

选词、四码上屏和拼音反查跟着方案走，各端一样。调整词序各端都有，入口不同。翻页键、Shift 切换和造词快捷键是 macOS 上的按键，写在后面。

## 各端相同

| 按键 | 作用 |
| --- | --- |
| 空格 | 上屏第一个候选 |
| `1` – `9` | 选择对应序号 |
| 回车 | 不上屏候选，直接交出已经打出的编码字母 |
| Esc | 清空当前编码 |

输入满四码且只剩一个候选时自动上屏（默认开启，可在「输入习惯」关闭）。`date` 这类有多项候选的编码不会自动上屏。

不会拆的字，用 **`z` + 拼音** 反查。拼音输完可以按 `'` 结束反查，再从候选里选字上屏。例如不知道「玫」的五笔时，打 `zmei`，在候选里选「玫」。

## 调整词序

同编码下的词可以改顺序。macOS 和 Windows 用快捷键打开，iOS 和 Android 在输入界面有对应按钮。各端都可以拖动排序。

| 系统 | 入口 |
| --- | --- |
| macOS | 默认 ⌃⌥0，可在「输入习惯」页的「排序」里修改 |
| Windows | 默认 Ctrl + Alt + 0，可在「输入习惯」页的「排序」里修改 |
| iOS、Android | 输入界面上的对应按钮 |

## 四码唯一、空码清空与回车清码

macOS、Windows、Android 在「输入习惯」页、iOS 在输入页可调：

| 开关 | 默认 | 作用 |
| --- | --- | --- |
| 四码唯一上屏 | 开 | 打满四码且只有一个候选时自动上屏 |
| 空码清空 | 关 | 打满四码仍没有候选时自动清空编码 |
| 回车清码 | 关 | 编码中按回车只清空编码，不把已经打出的编码字母交给应用 |

三项都在按键时直接判断，改完立即生效。`z` 开头的拼音反查和 `date` / `time` 等预置编码不参与。

## macOS

默认按五笔习惯。翻页和「二三候选」写在 Rime 配置里，改完后下一次按键生效。造词快捷键改完立即生效。

### 选词和翻页

| 按键 | 作用 |
| --- | --- |
| `;` `'` | 第二、第三候选。可在「输入习惯」页关掉，只留数字键 |
| `-` `=` 以及 `,` `.` | 翻页。可以改成只用其中一套，或改成 `[` `]` |
| Tab / ⇧Tab | 下一项 / 上一项候选 |

每页候选数在「外观配置」里调，范围 3–9，默认 9。候选条收成圆点或完全隐藏时，数字键仍然有效。

### 中英文

**单独按一下 Shift**（按下再松开，中间没有别的键）在中文和英文之间切换。英文模式下按键直接上屏。

切换时，光标旁会短暂显示当前状态：中文、英文，或大写锁定开启时的「大写」。大写优先于中英，样式相同。

按住 Shift 打大写字母，不会当成切换。造词窗口或删除确认框开着时，Shift 留给窗口，不切换模式。也可以用 ⌃⇧2 切换中英。

### 造词和删词

| 按键 | 作用 |
| --- | --- |
| Control + Option + N | 打开「添加自造词」。组合键可在「输入习惯」页修改 |
| Control + Option + 1 – 9 | 候选出现时，删除对应序号的词。修饰键跟着造词快捷键走 |
| Control + Option + 0 | 候选出现时打开排序窗口。组合键可在「输入习惯」页的「排序」里单独修改 |

细节见 [自造词](/guide/custom-words#macos)。

### 方案和字符

| 按键 | 作用 |
| --- | --- |
| ⌃⇧1 | 五笔 / 拼音方案切换 |
| ⌃⇧2 | 中文 / 英文 |
| ⌃⇧3 | 全角 / 半角 |
| ⌃⇧5 | 常用字集 / 扩展字集 |

### 编码里移动光标

还没上屏时，可以用 Emacs 风格的键编辑编码：

| 按键 | 作用 |
| --- | --- |
| ⌃B / ⌃F | 左移 / 右移 |
| ⌃A / ⌃E | 移到行首 / 行尾 |
| ⌃H | 删掉光标前一个字母 |
| ⌃G | 取消输入 |
