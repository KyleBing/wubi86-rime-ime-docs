# 注册与付费

玫枫五笔输入法本身**免费下载、免费使用**，不登录也能正常打字、造词、改标点。付费只与 **portal 账号** 有关，用来在多设备之间 [同步个人词库](/guide/lexicon)。

## 付费包含什么、不包含什么

| 项目 | 是否需要账号 / 付费 |
| --- | --- |
| macOS / Windows / iOS 输入法安装与日常输入 | 不需要 |
| 本机自造词、分组、标点、皮肤等设置 | 不需要 |
| 个人词库 `wubi86_jidian_user.dict.yaml` 的云端备份与多端同步 | 需要 portal 账号（注册需邀请码，见下文） |
| 主码表、扩展词库、其它自定义 dict 的双向同步 | **不提供**（扩展词库可单向拉取，见 [词库与同步](/guide/lexicon#扩展词库)） |

也就是说：**你付的是词库同步所用的服务器与维护成本**，不是买输入法授权，也不是买整包词库或主码表。

## 为什么要付费注册

个人词同步要把词条保存在云端，并在 Mac、Windows、iOS、码表助手之间合并、推送，需要长期运行的接口与存储。注册费（目前 **¥6**，与 [管理后台申请页](https://kylebing.cn/wubi/manager/#/register-apply) 收款码一致）用于**服务器租用**，让玫枫五笔和同步服务能持续维护下去。

没有同步需求时，可以一直不注册账号。

## 注册流程

1. 打开 [注册申请](https://kylebing.cn/wubi/manager/#/register-apply)。
2. 填写联系邮箱、选择支付宝或微信，按页面金额扫码支付。
3. 在表单中填写**付款账户信息**（支付宝/微信昵称或账号，便于核对到账）。
4. 提交申请。一般在 **1 个工作日内** 完成审核，结果会发到邮箱；通过后会附 **邀请码**。
5. 打开 [注册](https://kylebing.cn/wubi/manager/#/register)，填入邀请码、昵称、邮箱和密码，完成注册。
6. 按邮件提示完成**邮箱验证**，再在输入法「设置 → 账户」或管理后台登录。

管理后台入口：`https://kylebing.cn/wubi/manager/`。接口地址是 `https://kylebing.cn/wubi/portal/`；说明站在 `/wubi/`，不要把说明站地址当成接口前缀。

登录后可在各端打开自动同步，或手动对比、合并、覆盖个人词库，规则见 [词库与同步](/guide/lexicon)。
