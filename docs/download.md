# 下载

输入法目前可以下载的是 macOS、Windows 和 Android；iOS 可通过 TestFlight 参加公测，App Store 正式版尚未上架。

链接都指向各自仓库的最新正式版，地址固定，发新版本时只会换里面的安装包。安装包和更新清单都只放在 GitHub Releases，本站和其他服务器不托管任何安装文件。

## macOS

[下载 macOS 版](https://github.com/KyleBing/wubi86-rime-ime-macos/releases/latest/download/MeifengWubi-macOS.dmg)

需要 macOS 13 及以上，Apple 芯片与 Intel 都可用。装法与版本记录见 [macOS](/macos)。

## Windows

[下载 Windows 版](https://github.com/KyleBing/wubi86-rime-ime-windows/releases/latest/download/MeifengWubi-Windows-setup.exe)

需要 Windows 10 / 11 x64。装法与版本记录见 [Windows](/windows)。

## Android

[下载 Android 版](https://github.com/KyleBing/wubi86-rime-ime-android/releases/latest/download/MeifengWubi-Android.apk)

需要 Android 8.0 及以上。装法与版本记录见 [Android](/android)。

## 五笔码表助手

[下载五笔码表助手](https://github.com/KyleBing/wubi-dict-editor/releases/latest)

编辑五笔码表的桌面工具，支持 macOS、Windows、Linux。安装包在 Releases 页面，按系统选对应文件即可。
