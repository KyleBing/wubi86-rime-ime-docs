# 痛点解决

这一页写各端都会有的能力，不写某个系统怎么摆候选、怎么安装。macOS、iOS，以及以后的 Windows、Android，输入引擎都是 librime，方案都是 [rime-wubi86-jidian](https://github.com/KyleBing/rime-wubi86-jidian)。

## 都会有的功能

### 还是原来的五笔方案

方案 id 是 `wubi86_jidian`，码表是 86 极点。不另做一套编码，也不靠 Lua 改候选。四码唯一时自动上屏，`date` 这种多项候选不会自动上。

### 调整词序

同编码下的词可以改顺序，各端都可以拖动排序。macOS 和 Windows 默认是 ⌃⌥0 / Ctrl + Alt + 0，可在「输入习惯」页的「排序」里单独修改。iOS 和 Android 在输入界面有对应按钮。见 [快捷键](/guide/shortcuts#调整词序)。

### 模式提示

焦点进入输入框或切换中英时，光标旁会短暂显示当前状态。桌面端在同一处显示「中文」或「英文」；开启大写锁定时改为显示「大写」，优先于中英。iOS 键盘用键帽上的大小写状态提示，不弹这个浮层。

### 空码清空与回车清码

打满四码仍没有候选时可以自动清空编码，编码中按回车也可以只清码、不上屏字母。两项都在设置里单独开关，默认关闭，与方案原本的行为一致。iOS 在输入页里打开。

### 快捷键自造词

不用打开词库文件再部署。编码规则各端相同，见 [自造词](/guide/custom-words)。Mac 上默认是 Control + Option + N；iOS 在键盘里直接造。选中的文字或刚上屏的词会填进去，写完马上能打。

### 词库自动同步

只同步个人词库 `wubi86_jidian_user.dict.yaml`（约 40 000 字 / 5 000 条上限），主码表与其它 dict 需手动添加。先查云端修订号，没变化就不再整份下载。本地删掉、云端没改过的词不会被加回来。推送冲突会重新合并再推一次。对比、合并、覆盖和示意见 [词库与同步](/guide/lexicon)。账号与付费说明见 [注册与付费](/guide/register)（输入法免费，付费仅用于词库云端同步）。

### 用户词和主码表分开

自造词进用户词，按分组管理。主码表文件不动。同编码的词会标出来自用户词、扩展词库还是主词库。

### 标点由输入法处理

可以改每一键打出什么，并选择直接上屏或先进入候选。Mac 和 iOS 用同一套标点设置。

### 日期、时间和星期

输入 `date`、`time`、`week`，候选来自当时的系统时间。格式从「2026-10-09」到时间戳都有。完整列表见 [日期与时间](/guide/date-time)。

### 拼音反查

不会拆的字，用 `z` 加拼音反查。例如不知道「玫」时打 `zmei`，再从候选里选。
