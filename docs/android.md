# Android

仿系统键盘的五笔，设置 App 与键盘扩展共用同一套 `wubi86_jidian` 词库。版本 **1.0.1**。用码表引擎做五笔检索，不嵌入 librime，避免键盘进程体积和内存超限。造词、自动同步、标点和日期见 [痛点解决](/pain)，个人词同步见 [词库与同步](/guide/lexicon)。

## Android 上的做法

- **三页键盘。** 字母、数字、符号。深浅色跟着系统走。
- **候选在键盘上方。** 点候选上屏，也可以展开看更多。调整词序在输入界面有对应按钮，可以拖动排序。见 [调整词序](/guide/shortcuts#调整词序)。
- **键盘里就能造词。** 写入用户词后马上能打出来。主 App 里可以按分组管理、导入和导出。
- **四码唯一上屏。** 默认开启；可在「输入习惯」里关闭。单独按 `z` 可调出上次上屏的字词。
- **空码清空与回车清码。** 打满四码仍无候选时自动清空编码；编码中按回车只清码、不上屏字母。两项在「输入习惯」里开关，默认关闭。
- **自动同步的节奏。** 打开后约 2 秒查一次，改词后约 3 秒再同步，留在前台时大约每 10 分钟查一次。键盘收起后系统不能保证仍每 10 分钟跑，下次打开键盘会补上。
- **局域网里改配置。** 手机和电脑在同一 Wi‑Fi 时，打开「词库管理 → WiFi 管理词库文件」，用浏览器查看、上传、删除配置，再部署。离开该页后服务关闭。
- **标点与 Mac / iOS 相同。** 每一键的输出和上屏方式可以改。

## 安装

1. 下载 APK，用系统安装器安装（需允许「未知来源」或按厂商提示确认）。
2. 打开「玫枫五笔」App →「启用键盘」→「打开输入法设置」。
3. 系统设置 → 系统 → 语言和输入法 → 屏幕键盘 → 管理键盘 → 启用「玫枫五笔」。
4. 在任意输入框调出键盘，从系统键盘列表选「玫枫五笔」。

装好之后按 [开始输入](/guide/install) 里的方式打。快捷键与选词见 [快捷键](/guide/shortcuts)。
